MERN · Security tooling

Asset & Vulnerability Tracker

A security team lists its websites and servers, logs the vulnerabilities found on each, and tracks every one until it is fixed.

  • JWT sign-in with Admin and Analyst roles, enforced on the server. Nobody can register as an Admin.
  • Dashboard numbers come from one MongoDB aggregation, cached in Redis and cleared on every write. If Redis is down, the API keeps answering.
  • Filters, search and pagination live in the URL; RTK Query tags refetch the dashboard the moment a status changes.
  • bcrypt, a pinned JWT algorithm, NoSQL-injection filtering, per-IP rate limits and a strict CSP from nginx.

MERN · Background jobs

Website Security Header Scanner

Enter an address and a background worker checks its HTTPS setup and seven security headers, then grades it from A to F with a one-line fix for every problem.

  • The API answers 202 Accepted at once. A BullMQ worker in its own container does the fetching, retries network errors once and recovers stalled jobs.
  • Redis does three jobs: a 10-minute result cache, an in-flight lock so two identical scans share one job, and a per-IP rate limit that holds across API containers.
  • The SSRF guard runs inside the HTTP client's DNS lookup, so every redirect hop is checked and DNS rebinding is blocked.
